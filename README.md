# LabHub 实验室设备预约与管理系统

软件工程大作业 · 生成式软件工程（AI Agent 全生命周期协同开发）

## 一、快速启动

环境要求：**Python 3.10+**（零第三方依赖，无需 pip install）

**方式一（推荐）**：双击本目录下的 `启动演示系统.bat`，浏览器会自动打开 http://127.0.0.1:8080

**方式二**：命令行启动

```bash
cd LabHub/app
python server.py            # 启动后访问 http://127.0.0.1:8080
```

> 若 8080 端口被占用，可指定其他端口：`python server.py 8099`

演示账号（首次启动自动写入种子数据）：

| 账号 | 密码 | 角色 | 说明 |
|------|------|------|------|
| `admin` | `admin123` | 管理员 | 设备档案、信用治理、审计日志、统计 |
| `teacher1` | `123456` | 教师 | 审批预约、全量台账、统计报表 |
| `stu001` | `123456` | 学生 | 完整预约/签到/签退流程 |
| `stu002` | `123456` | 学生 | 信用分 55，用于演示低分拦截 |

功能入口：登录后左侧导航按角色动态展示（工作台 / 设备目录 / 我的预约 / 审批中心 / 预约台账 / 用户与信用 / 审计日志 / 信用记录）。

## 二、测试与数据

```bash
# 重置数据库（服务运行中也可执行）
python tools/reset_db.py

# 运行 32 条接口自动化用例（端口与 server 一致）
python tests/api_test.py 8080
```

测试结果会写入 `tools/test_results.json` 并被报告引用。

## 三、重新生成交付物

```bash
python tools/make_figures.py     # 重新生成 10 张工程图表 -> docs/figures/
python tools/build_report.py     # 重新生成报告 DOCX -> docs/
```

修改图表数据请编辑 `tools/project_data.py`（缺陷台账、AFS 评分、任务分级等均在此统一维护，
图表与文档自动保持一致）。

## 四、目录结构

```
LabHub/
├── app/                     # 演示系统
│   ├── db.py                # DDL / 连接 / 种子数据
│   ├── errors.py            # 统一异常体系
│   ├── repos.py             # 仓储层 + UnitOfWork
│   ├── services.py          # 业务规则（冲突检测 / 信用 / 状态机）
│   ├── server.py            # HTTP 路由 / 鉴权 / 异常映射
│   ├── static/              # 前端 SPA（原生 HTML/CSS/JS）
│   └── data/labhub.db       # SQLite 数据库
├── tests/api_test.py        # 32 条接口用例
├── tools/                   # 图表 / 报告 / 数据重置 / 项目数据源
└── docs/                    # 交付文档与全部图表
```

## 六、业务规则速览

- 预约校验链：角色 → 信用分 ≥ 60 → 设备可用 → 时间窗（开放时间 / 单次时长 / 提前 5 分钟 / 7 天内）→ 时段冲突（PENDING 同样占位）
- 信用规则：完成 +2；提前 <2h 取消 −5；超时 30 分钟未签到 −15；<60 禁止预约；=0 自动停用
- 审批：`requires_approval` 设备需 TEACHER/ADMIN 审批，且不能审批自己的申请
